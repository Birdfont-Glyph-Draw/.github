## What Is Birdfont

Birdfont is a drawing helper for making a modest typeface. Birdfont glyph draw is the heart of it: one cell, one letter, a curve you can still explain. A student in a design class, or someone at home making letters for a zine, can finish a short character set without pretending to run a foundry.

After the shapes exist, Birdfont letter spacing gives every glyph a basic side space, and Birdfont kerning pair fixes the pairs that still look wrong. Birdfont svg path is optional, for a logo-like character you drew as vectors. Birdfont font export is the moment you try the alphabet in a real sentence. Keep the first face small: capitals, or lowercase, or a few dingbats. A complete commercial family is a later ambition.

Work in a repeatable order. Draw in Birdfont glyph draw, set Birdfont letter spacing, then touch only the worst Birdfont kerning pair examples. Import a Birdfont svg path only when the outline is already clean. Use Birdfont font export to test, then return to the drawing if a letter fails in a word.
